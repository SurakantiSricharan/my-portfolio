HybridSense-X: 4-Class Sentiment & Ambivalence Disentanglement

A state-of-the-art Deep Learning architecture that extends conventional 3-class sentiment models by explicitly identifying concurrent opposing sentiments (e.g., "Great performance, but terrible battery"). Combines CNN spatial feature extraction, BiLSTM sequential context, and Attention pooling with clause-level disentanglement.

5 models trained & benchmarked (CNN, BiLSTM, DistilBERT, Baseline TF-IDF, Hybrid Attention).
Interactive Streamlit dashboard with SQLite telemetry, XAI token attribution, and latency tracking.
Trained on 45,586 multi-class sentiment samples with verified class distributions.
Python TensorFlow / Keras PyTorch DistilBERT Streamlit SQLite

Automatic Keyword & Keyphrase Extraction

An automated NLP text analysis engine that parses lengthy academic research papers and documents, extracting the highest-salience n-grams (1-gram and 2-gram keyphrases) using custom-tuned TF-IDF weighting and sparse matrix ranking.

NLTK tokenization, custom domain stop-word filtering, and WordNet lemmatization pipeline.
Interactive web interface supporting instant file uploads, sorting, and vocabulary search.
Python Scikit-Learn NLTK Flask Jupyter
