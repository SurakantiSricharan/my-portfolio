## 🚀 How to Run Locally

You can run this portfolio in two simple ways:

### Option 1: Direct File Opening
Double-click `index.html` to open it immediately in Google Chrome, Microsoft Edge, or any browser of your choice.

### Option 2: Local HTTP Server (Recommended)
From this directory, run:
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🌐 How to Deploy for Free to GitHub Pages

1. Create a repository on your GitHub account named: `SurakantiSricharan.github.io` (or any repo name like `portfolio`).
2. Push the files in this directory to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/SurakantiSricharan/SurakantiSricharan.github.io.git
   git push -u origin main
   ```
3. Go to **Settings > Pages** in your GitHub repository, choose the `main` branch, and click **Save**.
4. Your website will be live worldwide at: `https://SurakantiSricharan.github.io/`!
